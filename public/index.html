Коротко

Один адрес — один основной код. Алиас добавляет ещё один, обновление меняет основной, удаление стирает все.

6
знаков

Вставьте адрес вроде itHub.ru. Строка из цифр, например 12345, не подойдёт.

{
  "original": "ithub.ru",
  "short": "http://…/a8Kd2Q",
  "created": true
}

/create

Новый код, если адреса ещё нет. Если есть — вернётся прежний, created: null.

/refresh

Заменяет основной код. Старый основной адрес больше не открывается.

/alias

Добавляет ещё один код к тому же адресу. Если адреса нет — создаёт его.

/remove

Удаляет все коды этого адреса. Чужие записи не трогает.
